# Security Policy

Bitte keine Sicherheitslücken mit echten Dokumenten oder API-Schlüsseln in öffentlichen Issues melden. Reproduktionsdaten müssen anonymisiert sein.

Der MVP verarbeitet potenziell sensible Klausuren und Notizen. Produktionszugang ist deshalb auf zwei manuell angelegte Konten beschränkt; öffentliche Registrierung muss deaktiviert bleiben. Details zu RLS, Storage und Secret Handling stehen in `docs/ARCHITECTURE.md` und `docs/OPERATIONS.md`.
